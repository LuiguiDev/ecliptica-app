# ecliptica-app

Web app (Vite + React + Three.js) que explica el movimiento aparente del Sol sobre la eclíptica y el zodiaco.

La escena muestra el Sol al centro, la Tierra orbitando la eclíptica y una flecha Tierra → Sol → constelación que indica el signo zodiacal frente al que "se ve" el Sol en cada fecha. Incluye las 12 constelaciones del zodiaco, un slider de fecha (día del año), control de velocidad y cámara orbital.

## Ejecutar en desarrollo

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
```
